# 通缉令首版交付

负责人 Solazhu · 2026-11-18 · WantedPoster 0.1.0-test

## 使用

把安装包里的 WantedPoster 文件夹放进《魔兽世界：Forever》的 Interface/AddOns，进入游戏后输入 /wanted 打开面板。选中玩家可以点「加入当前目标」。已知完整姓名时，可以粘贴「名 姓」并点「加入」，也可按回车提交。

每次真实登录开启一组，/reload 继续当前组。上方箭头切换登录组，下方箭头切换页。名单在同组内按完整姓名去重。每页最多五人，构造宏时计入命令、换行和 UTF-8 字节数，达到 255 字节后续用下一页。

点姓名查找单人，点「搜本页」按显示顺序执行本页的 /tar 命令。行尾叉号移除一条记录，「清空本页」确认后移除本页的记录。插件为当前页复用最多六个角色宏，按游戏确认保存的宏正文绑定按钮。遇到用户的同名宏时选择新名称。

战斗中，在已打开的面板可以粘贴姓名，或在客户端给出可读完整姓名时记录当前目标。已同步的查找按钮可以继续使用。翻页、清理、打开和关闭面板都在脱战后进行。新记录会在脱战后刷新到对应的查找按钮。
