# 法术效率：德鲁伊耗蓝技能适配

负责人、开发及测试：Solazhu

日期：2026-11-16

## 范围与实现

基于 `ab9b5833c38b62a2e8de1678f0f8979359636c14`，在 `codex/spell-efficiency-druid` 分支开发。用户确认本轮仅适配耗蓝技能，怒气、能量技能显示“不适用”；发布版本为 `0.1.5-test`，已获授权提交、推送、合并至 `main` 并安装到游戏目录。

- 牧师与德鲁伊共用职业入口判断；两者均显示小地图按钮并启用技能悬停计算。其他职业暂不启用。
- 按实际悬停的已学等级读取面板效果、费用和施法时间，沿用 `效果／耗蓝／有效占用时间^权重`；小地图操作、红蓝显示、按角色保存、手动权重均保留。
- 根据法术费用接口的资源类型及当前光环条件选择费用，不使用角色当前资源条判断。有效费用包含非蓝资源时返回“不适用”；缺失、空表或不可读取的费用不伪装成零耗蓝。
- 英文愈合类 `heals ... and another N over X sec` 补计完整后续治疗；未确认数量、单位或来源时不输出部分总量。复生不算作战斗治疗；虫群类固定命中惩罚不会被误当成随机伤害触发，真正的概率效果仍拒绝估算。
- 只扩展现有模块，无新运行依赖、轮询或历史记录。

## 验证与边界

修改前用新增场景验证，旧实现出现 12 项失败，涵盖职业入口、资源区分及文本漏算。修改后运行 `tests/run_tests.py`，Lua 5.1 下共 268 项通过：法术效率 104 项，拍卖助手 164 项；法术效率净新增 13 项测试。

样本覆盖各等级直接治疗、持续治疗、直接加持续治疗，自然与奥术直接伤害、直接加持续伤害、控制附带伤害，宁静与飓风类单目标完整引导；另含能量、怒气、连击点、不同形态生效费用、零耗蓝和费用未就绪、急速变化、权重设置、重载恢复及原牧师行为。数值与 ID 为合成数据，未作为实际技能数据写入插件。

接口字段对照无限服 UI 源码镜像的 [`GetSpellPowerCost`](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/SpellDocumentation.lua) 和 [`SpellPowerCostInfo`](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/SpellSharedDocumentation.lua)。后者明确费用可依赖当前变形或光环，接口返回空值仍不能证明免耗蓝。

标准级代码复核及独立架构复核完成，未发现需要修复的新增问题；三处职业入口、费用返回值调用方、加载顺序和牧师兼容均已检查，`git diff --check` 通过。

未进行游戏内逐技能文本验证。荆棘反伤、依赖目标已有持续效果的治疗等条件能力仍需可确认的面板总量，否则保留不可估算状态，不建立战斗模拟；每秒耗蓝尚不纳入现有固定费用模型。

安装包为 `SpellEfficiency-0.1.5-test.zip`，仅包含本插件 TOC、三个 Lua 文件和 README。发布时校验包内容与提交一致，安装前备份旧文件，安装后验证哈希并运行对应离线测试；不改写其他插件或 SavedVariables。实际提交、远端引用与安装校验凭据保存在本地 `.tools/ship-spell-efficiency-0.1.5/`，游戏内验证由用户 `/reload` 后进行。
