# 法术效率区间显示

开发及测试由 Solazhu 记录。日期为 2026-11-25。

在当前治疗修复版基础上，分支 `codex/spell-efficiency-range` 为牧师和德鲁伊增加「显示效率区间」复选框。复选框位于原「显示法术效率」右侧，随「应用」或回车生效。该设置按角色保存，旧配置默认显示平均值。

上下限使用相同的耗蓝和有效占用时间。持续效果按现有跳数计算。同类别的多个效果分别累加上下限，按伤害比例回血沿用对应的伤害区间。固定数值仍显示一个数。强效治疗术截图的数据以默认权重计算，关闭时显示蓝色「治疗 1.17」，开启时显示「治疗 1.11–1.24」。

完整离线回归通过 313 项，其中法术效率 149 项。新增和扩展用例覆盖截图、开关应用、关闭、重载保存、旧配置、无效权重、苦修、持续与关联效果、混合颜色、护盾和零下限。游戏客户端中的显示待实测。
