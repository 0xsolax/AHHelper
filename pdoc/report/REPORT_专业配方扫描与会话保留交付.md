## 交付结果

打开拍卖行与专业制作页，选择配方后点击专业窗口右上角「扫描利润」，即可查询成品及所需材料并计算利润。扫描窗口展示售价、含手续费总成本、单件利润、利润率和报价时间，支持排序、制作成本明细及悬停材料详情。

每个配方保留本次会话最近的完整测算。关闭专业、拍卖行、扫描窗口或插件页均不清理，监控列表中的「配方扫描记录」可重新打开。退出游戏、换角色或 `/reload` 清理扫描记录；已主动加入的监控继续保留。新记录不会自动加入监控，同来源配方重复加入也不会覆盖原配置。

完整新结果替换旧测算；空市场或材料不足不沿用旧利润。网络失败、中断与限流超时保留旧结果和报价时间并显示失败。扫描快照独立于随后发生的其他行情更新。原生成品、材料和产量读取、查询队列、成本算法均复用既有能力，未添加运行模块或保存数据库字段。

## 游戏内验收

1. 先备份现有插件，再试用本包；原保存数据保留。打开拍卖行、打开专业，确认「扫描利润」按钮位于标题栏右侧且没有遮挡原生按钮。
2. 依次扫描两项普通材料或消耗品配方，核对原生成品、材料用量、最低产量、售价和手续费；分别查看排序和悬停明细。
3. 关闭制造业、拍卖行和扫描窗口后重新打开「配方扫描记录」，确认两项结果与原时间保留；等待两分钟后应显示历史。
4. 在扫描途中切换原生选中配方，结果仍归属点击扫描时的配方；中断重扫应保留旧结果并标注失败。
5. 将一项加入监控，再重复操作，确认不重复新增、不修改已有材料价格。重载后扫描记录为空，已加入的监控仍在。

真实客户端界面布局、专业 API 返回、网络时序和服务端限流尚未实机验证。固定成品、固定物品材料以外的复杂品质、可选材料、装备属性变体等仍沿用现有不支持提示。利润是挂单价测算，不代表实际成交或销售速度。
