# 原生出售页正常锁回填修复

负责人、修改人、操作人：Solazhu

日期：2026-11-12

版本：AuctionPilot 0.6.2

点击“准备上架”后，原生出售页会锁定当前背包物品。原回填逻辑把这个正常锁误判为库存变化，在先清零数量后退出，导致数量、单价和时长无法带入。

修复仅移除交接完成阶段对锁位的拒绝；交接前仍拒绝锁定物品，回填前继续核对表单物品、物品编号、GUID、存在性、可售资格、可售数量及战斗状态。插件不主动解锁，最终创建拍卖仍由用户点击原生按钮完成。原生锁行为依据为[固定版本界面源码](https://github.com/Gethe/wow-ui-source/blob/4cd0ab752a77164f654ccbca9d0c1fe8dafceebe/Interface/AddOns/Blizzard_AuctionHouseUI/Shared/Blizzard_AuctionHouseSharedTemplates.lua#L545-L565)。

## 验证

先让测试中的原生出售页模拟真实加锁，再运行旧代码：要求回填 20 件时实际为 0，回归测试失败。应用修复后，本地及独立目录中的 112 项 Lua 5.1 测试均通过，包括商品与普通物品、预先锁定、物品消失或替换、库存变化、延迟初始化、手动编辑、关闭、超时和禁止插件直接交易。独立目录仅包含已提交的 0.6.2 基线与本次三个代码及测试文件的补丁，补丁逐字节比对一致。

复核覆盖安全、接口组合、输入假设和失败传播；没有剩余确证问题。结果来自源码及离线测试，游戏内回填仍需实际验收。
