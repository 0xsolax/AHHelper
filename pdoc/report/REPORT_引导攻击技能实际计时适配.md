# 引导攻击技能实际计时适配

负责人、开发及测试：Solazhu

日期：2026-11-17

## 目标与范围

基于 `3152522a3f55dc7aad40fc16b3c2505595ccf655`，在独立分支 `codex/spell-efficiency-channel-damage` 适配精神鞭挞等引导攻击技能。按完整面板总伤害和实际完整引导时间计算效率，复用苦修的首次施法校准、急速失效、再次施法校准与面板回退。

沿用当前牧师、德鲁伊职业范围，以及单目标、耗蓝和手动时间权重口径。纯治疗引导沿用面板时间；不扩展其他职业，不增加界面栏位，本轮未提交、推送、合并或安装。

## 最小实现

- 现有解析已经区分整段总量与每跳效果，不需要另建技能数据库。记录条件从苦修专用标记改为存在可解析伤害，并保留玩家引导开始事件、已学会法术、准确法术 ID 及有效时间差校验。
- 提示框使用计时前仍须识别为引导并包含伤害；普通瞬发持续伤害不会因文本中的持续秒数或旧记录改用引导时间。
- 将已有引导开始事件注册扩展到全部已支持职业，使德鲁伊的引导攻击也能校准。苦修双效果、按法术 ID 隔离的会话记录、急速失效、失败回退和评分函数全部复用。
- 删除已经无调用方的苦修类型返回标记。没有新增运行时文件、配置、缓存结构、轮询或外部依赖。

完整伤害取当前描述；若描述给出每跳数值，跳数来自描述中的间隔和完整持续时间。实际计时只替换分母，不重新计算跳数，也不向普通引导套用苦修的立即首发规则。效率仍为 `总伤害 / 耗蓝 / max(完整引导秒数, 当前 GCD 秒数)^时间权重`，实际时间不再除以急速。

## 验证

修改前原有 290 项测试通过。先补回归：原有解析通过精神鞭挞式总量和每跳文本用例，但模拟接口返回完整 2 秒时仍使用面板 3 秒，显示 2.49 而非应有的 3.45，复现未接入校准的问题。

修复后 Lua 5.1 全部 306 项通过，其中法术效率 142 项、拍卖助手基线 164 项。新增 16 项覆盖：

- 中英文整段总伤害、每跳伤害与减速百分比的区分；改变实际时间不改变总跳数。
- 校准后即时更新、未悬停时校准、同名不同等级费用和时长隔离，以及苦修与其他引导技能互不串用。
- 急速变化、相同急速事件、隐藏期间急速往返、急速不可读和恢复；实际时长不变时不制造效率提升。
- 受击更新、提前中断、停止事件、错误或不匹配的接口数据，以及下一次施法恢复。
- 不确定跳数保持无法估算，免费及非蓝费用继续按现有规则处理；纯治疗引导与普通持续伤害不进入实际计时评分。
- 德鲁伊全新登录时的飓风式单目标完整伤害、GCD 和时间权重、重复悬停单行显示及重载清理。

测试使用合成数值、法术 ID 和引导时间，不作为实时技能数据库。样本总伤害 600、耗蓝 100，默认权重 0.8：面板 3 秒得到 2.49，实际 2 秒得到 3.45。原有苦修 12 项计时用例和各职业回归继续保留；其中旧的“其他引导不校准”预期改为“各技能分别校准、不覆盖苦修”。

## 实机边界

本轮没有在游戏中施法。实际伤害仍来自当前客户端提示，未额外模拟面板未体现的天赋、暴击、抗性或目标数量。无法解析的描述不输出部分估值；真实计时不可读时回退面板，下一次施法可以重新校准。

后续授权安装后，可分别检查精神鞭挞当前及低等级在首次施法前后、急速变化后重新施法、提前中断和 `/reload` 后的效率；德鲁伊检查引导攻击仍按单目标计数，纯治疗引导保持原有口径。
