# 法术效率小地图入口与手动时间权重

负责人、开发及测试：Solazhu

日期：2026-11-16

## 范围与结果

基线为 `1bacbc20b9b0d028e759ae4566fe90a1c6c4ef32`，开发分支为 `codex/spell-efficiency-minimap-settings`。仅修改法术效率插件及对应测试、说明；拍卖助手未改动。本次发布版本为 `0.1.4-test`，用户已授权提交、推送、合并至 `main` 并安装到游戏目录。

- 小地图左键打开设置，右键开启／关闭效率提示，左键拖动调整位置。
- 时间权重可手填 `0～1`，默认 `0.8`；公式为“效果／耗蓝／有效占用秒数的权重次方”。`0` 只计算每蓝效果，`1` 完整计入时间；读条与 GCD 仍取较大值，引导仍按完整引导时长。
- 应用或回车立即生效；非法输入保留原开关和权重。恢复默认会开启显示并恢复 `0.8`，按钮位置不变。
- 按角色保存开关、权重、按钮角度三个值，不保存历史。只在拖动期间逐帧定位，松开或隐藏后停止。
- 关闭显示会移除当前技能提示框中的效率行；重新开启或修改权重会更新当前有效技能提示框。隐藏、物品、光环及其他不支持的提示框不复用旧技能。

新测试覆盖权重端点与中间值、混合技能红蓝数值、输入校验、真实按钮回调、启停与即时更新、缺少时间数据时的零权重、缩放下拖动及释放、重载持久化、损坏配置恢复、延迟加载及非牧师角色。

接口核对使用客户端 UI 源码镜像的 `forever` 分支，检查原生复选框与输入模板，以及 `GameTooltip:RebuildFromTooltipInfo()` 的重建流程。没有引入外部运行库。

标准级代码复核及独立架构复核完成，未发现需修复的问题。检查了可选参数兼容、配置恢复时序、模块依赖方向、提示框来源隔离和拖动更新的释放；`git diff --check` 通过。
