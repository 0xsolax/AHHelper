# 材料列顺序与整档采购额交付

负责人及操作人：Solazhu  
日期：2026-11-12  
版本：AuctionPilot 0.6.2

材料行调整为：材料、用量、小计、采购均价、最低档数量、整档采购额、时间/来源。小计移到采购均价之前，数量独立成列；列表不再重复显示 AH 最低单价，该单价保留在悬停提示。

整档采购额按 AH 最低可买档位的单价乘该档外部可买量计算，排除自己的挂单，不包含更贵档位。配方小计和采购均价仍按所选来源及所需用量计算，因此商店价、固定价和跨档均价不会误用于整档采购额。该金额仅为最近一次查询的参考，不触发购买或额外查询。

无报价、失败、不完整、没有外部可买量时不显示零元采购；历史金额继续标识历史。资金超出精确计算范围时显示 --，过宽数量或金额用「悬停查看」替代，完整值放入提示。

功能实现仅修改 UI.lua；同步版本、使用说明、设计、回归测试和预览。没有新增保存字段、模块、依赖或交易行为。
