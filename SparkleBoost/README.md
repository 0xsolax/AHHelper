# 拾光 SparkleBoost 0.1.1-test

为《魔兽世界：无限》制作的物品可见性测试插件。目标接口 `16001`；本机读取到的客户端为 `1.60.1.70938`。

## 安装

将压缩包内的 `SparkleBoost` 文件夹放入：

```text
F:\GAME\World of Warcraft\_forever_\Interface\AddOns\
```

最终文件位置应为 `Interface\AddOns\SparkleBoost\SparkleBoost.toc`。首次添加插件后，完全退出游戏再启动，并在角色选择界面启用“拾光 SparkleBoost”。

已有安装覆盖更新后输入 `/reload` 加载新版。点击小地图上的拾光按钮或输入 `/sg` 打开 / 关闭设置，`/sg test` 打开效果预览。

按住小地图按钮的左键，沿小地图边缘拖动；松开后自动记住位置，正常重载或重新登录后恢复。位置按角色保存。关闭光效后按钮仍可用于打开设置。

普通设置会直接应用；战斗中涉及互动目标的设置延后到脱战。无需为每次调整执行 `/reload`。

## 使用

初次安装默认开启“保持原生任务闪光”。它会保持客户端原有的任务拾取闪光，修改画质预设后再次检查。

“附近增强（测试）”默认关闭。先在界面右侧预览，再勾选该选项，在有任务物品的地方测试。

附近增强提供：

- 星光、光柱、光圈三种样式。
- 0.6–3 倍大小、25%–150%亮度、上下位置调整。
- 5–15 码提示范围和前方 / 环视搜索。
- 任务物品、草药、矿脉、可拾取尸体的独立选项。
- 按类别配色，或统一金色、青色、紫色。
- “恢复原设置”和诊断输出。

## 实际能力与边界

原生闪光的开关不是大小或亮度参数。大小、亮度和样式控制的是插件叠加的界面光效，不会修改客户端原生粒子。

新增光效跟随游戏选出的一个互动目标，不能同时扫描并高亮屏幕上所有任务物品。范围仍受客户端限制，填写 15 码不等于保证每种物体都能在 15 码被识别。位置跟随姓名板，用“上下位置”校准。预览是界面演示，不是游戏实拍，也不代表世界遮挡或实际识别距离。

只有客户端提供的目标、任务和鼠标图标信息可以参与识别。未识别的物体不会被凭空标记；任务目标文字匹配只是补充识别，可能漏判或误判。

附近增强需要调整互动目标相关设置。上游方案曾发生无目标施法选中附近单位、尸体出现空姓名板的问题。本版保留遇到活体目标暂停、移动后恢复的处理，并在战斗中隐藏新增光效、延后受保护设置的修改；尚未实机确认其对所有施法、交互和姓名板插件组合的影响。测试附近增强时，确认无目标自疗仍落在自己身上；不符合预期就关闭该开关并使用“恢复原设置”。

不修改 `graphicsOutlineMode`、自身轮廓、全局画质、粒子密度、技能和按键绑定。检测到 Lueur 或 Forever Loot Sparkles 的 Herbs & Ores 增强扩展时，会暂停本插件的附近增强，避免双方改写同一设置。仅安装 Forever Loot Sparkles 原版时可共存。

## 恢复与卸载

1. 输入 `/sg restore`，或在设置中点击“恢复原设置”。
2. 脱离战斗，完全退出游戏，再移除插件文件夹。
3. 若要让已经显示的原生闪光消失，客户端可能需要完全重启；`/reload` 可能不足。

插件按角色记录实际改动前的值，只恢复仍等于本插件最后写入值的设置。之后由你或其他插件改写的值会保留。正常退出时也尝试恢复；崩溃或战斗中退出可能来不及恢复，记录会保留到再次加载插件后处理。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `/sg` | 打开 / 关闭设置 |
| `/sg test` | 打开预览，不会自行启用附近增强 |
| `/sg on`、`/sg off` | 启用 / 停用插件 |
| `/sg size 2` | 新增光效大小设为 2 倍 |
| `/sg brightness 120` | 新增光效亮度设为 120% |
| `/sg style beacon` | 光柱；也可用 `sparkles`、`ring` |
| `/sg palette cyan` | 青色；也可用 `auto`、`gold`、`violet` |
| `/sg range 15` | 请求 15 码范围，受客户端实际限制 |
| `/sg status` | 输出版本、设置及当前互动目标诊断 |
| `/sg restore` | 停用并恢复改动前的设置 |
